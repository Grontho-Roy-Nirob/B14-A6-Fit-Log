# 💪 FitLog

FitLog is a modern workout tracking app built with Next.js. Users can explore workouts, view details, create a daily plan, save workouts, and track their progress.

## 🚀 Live Demo

[Live Demo](https://fitness-hub-smoky.vercel.app/)

## 📂 GitHub Repository

[GitHub Repository](https://github.com/Grontho-Roy-Nirob/B14-A6-Fit-Log)

## 🛠️ Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React Toastify
* REST API
* LocalStorage

## ✨ Key Features

* Browse responsive workout cards.
* View detailed workout information.
* Add up to 5 workouts to Today's Plan.
* Save workouts for later.
* Track exercises, duration, and calories.
* Mark workouts as Done or remove them.
* Sort by Duration, Calories, or Rating.
* Toast notifications for user actions.
* LocalStorage persistence.
* Responsive design with custom loading and 404 pages.

## 🔌 API

FitLog uses a REST API to fetch workout data.

* **All Workouts:** `https://api.abcz.workers.dev/api/fitlog`
* **Workout Details:** `https://api.abcz.workers.dev/api/fitlog/:id`

## 📱 Pages

* `/` — Workout Library
* `/workouts/[id]` — Workout Details
* `/my-plan` — Today's Plan & Saved Workouts
* `/404` — Not Found
